Claude Code for non-programmers: fixing a Minecraft mod and a music app

FeatureOct 20, 2026Full read: 8 min on Substack

A crashing Minecraft mod, a YouTube Music app that needed offline mode, and the plan-first workflow (plus the cautions) that made both work.

The short version

We're not programmers. We wanted to see how far Claude Code, Anthropic's coding agent, could get on two pieces of software we didn't write, all on the $20-a-month Claude Pro plan.

First up was The Shooting Star [Demo], a brand-new Minecraft mod by rimuru.dev that we run on Fabric. Using its remote crashed the game every time. The cause was a render pipeline issue, and Claude Code fixed it in about 10 minutes. The mod is All Rights Reserved, so the fix stays on our machine. The right move is telling the author.

The bigger job was YTubic, NUber's open-source YouTube Music app. It's GPL-3.0, so we forked it as YTubic Plus and added a radio button, Spotify-style offline downloads and a Downloads page that works with no internet. That took 13 commits in about 68 minutes.

The speed wasn't the interesting part. With the Superpowers plugin, Claude asked what we wanted before it wrote anything, and we wrote down what would count as failure. It still got things wrong. The plan told yt-dlp to save files with a .part name, which yt-dlp strips, so every download looked failed. Two review passes caught 13 more problems. And saving audio this way is against YouTube's terms as written, so it's unofficial and your call.

Key takeaways

  • Questions first, code second. Say the goal in plain words, let it question you, and list what would count as failure even if the code works.
  • The plan can be wrong. Tests written from a wrong assumption still pass. Run the thing for real, on a copy.
  • Review passes earn their keep. Round one fixed 5 issues and round two fixed 8, including one that slipped past our own one-account rule.
  • The judgment calls are yours. Claude asked; we decided things like the 30-day offline check-in and one account only.
  • Check the license before you share. GPL-3.0 lets you fork and share. All Rights Reserved means keep the fix to yourself and tell the author.
  • Back up first. Saves, mod folders and app data, before you change anything.
